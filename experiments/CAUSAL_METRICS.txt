Naming note
-----------
The abstain verdict UNKNOWN was folded into INCONCLUSIVE (commit 181be1a);
report.go now emits exactly PASS / FLAGGED / INCONCLUSIVE / FAIL. There is
no UNKNOWN constant. This removes a four-way branch the judge/verifier did
not actually need and keeps "evidence missing" (abstain) distinct from
"evidence wrong" (fail) in every table below.

Provenance caveats (audit, 3 Nov 2026)
--------------------------------------
- Metrics 1-3 and 5 come from experiments.causal.deterministic_verdict, a
  Python reference that checks closure and dangling ids by set membership.
  That function cannot depend on span order, so flip_rate = 0 holds by
  construction; it is a consistency check of the sweep, not evidence that
  the Go pipeline is order-invariant. The Go canonical package is not yet
  wired into verify, and the grid traces are synthetic, not harness runs.
- The reference diverges from Go on two cases: a closed trace with no
  final answer is FAIL here but INCONCLUSIVE (final_answer evidence gap)
  in Go; and drop_link (below) is a miss here but INCONCLUSIVE in Go,
  where the causal_links obligation requires a link per consumed tool
  result. Both now take closure only from a root span.
- Metric 4 is a deterministic estimate scaled by DAG size, not a measured
  token count or wall-clock time.
- The live judge section below was re-run on 3 Nov 2026 over the full
  160-cell grid with current mid-tier models (Gemini via the Gemini API,
  DeepSeek and Kimi via OpenRouter), each at its minimum reasoning
  setting. Artifacts: artifacts/results-causal-judge-{gemini,deepseek,
  kimi}.json, all pinned to source checksum 9e423993... of
  results-causal.json. Earlier numbers (n=20, and the Nov 3 run on
  gemini-3.5-flash-lite / deepseek-v3.2) are superseded.
- Gemini direct reports no reasoning tokens in its OpenAI-compatible
  usage, so the Gemini cost below may undercount thinking at "low".

Grid
----
Offline grid: 40 distinct seeded executions (seeds 1..40 alternating the
flash/pro trace-shape families) x 4 conditions (clean + truncate_closed,
drop_link, orphan_link_target) = 160 cells. Every execution is a different
causal DAG: 80/80 distinct canonical SHA-256s over the default range,
invariant-verified by tests. Serialization bound: 20 valid topo orderings
per trace. Budget: deterministic per-trace token/duration estimates scaled
by DAG size (NO live spend in the offline grid).
