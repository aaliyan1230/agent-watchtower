Naming note
-----------
The abstain verdict UNKNOWN was folded into INCONCLUSIVE (commit 181be1a);
report.go now emits exactly PASS / FLAGGED / INCONCLUSIVE / FAIL. There is
no UNKNOWN constant. This removes a four-way branch the judge/verifier did
not actually need and keeps "evidence missing" (abstain) distinct from
"evidence wrong" (fail) in every table below.

Grid
----
Offline grid: 40 distinct seeded executions (seeds 1..40 alternating the
flash/pro trace-shape families) x 4 conditions (clean + truncate_closed,
drop_link, orphan_link_target) = 160 cells. Every execution is a different
causal DAG: 80/80 distinct canonical SHA-256s over the default range,
invariant-verified by tests. Serialization bound: 20 valid topo orderings
per trace. Budget: deterministic per-trace token/duration estimates scaled
by DAG size (NO live spend in the offline grid).
